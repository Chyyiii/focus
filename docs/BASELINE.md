## Как зафиксировать в git (делает собственник через сайт GitHub)
1. Репозиторий → «Releases» → «Draft a new release».
2. Tag: `focus-2.0-baseline`, Target: коммит `50bb8bb` (или `main`, если после него ничего не менялось).
3. Title: «FOCUS 2.0 — исходная точка». В описание вставить таблицу выше.
4. «Publish release». Откат к исходной точке: взять `index.html` и `sw.js` из этого релиза (при откате поднять номер кэша выше текущего).
