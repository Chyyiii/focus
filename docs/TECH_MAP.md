## 4. Режимы хранения и запуск
1. При старте `window.claude.use('db'|'user')` есть → режим `cloud` (артефакт Claude), иначе `local` (localStorage).
2. GitHub Pages всегда `local`.
3. Запись: цепочки `persistX` (очередь, чтобы не терять порядок), при ошибке всплывает сообщение.
4. Миграции встроены в `cleanX` (пример: старый `plan` → `tasks`).

## 5. Внешние зависимости
- Google Fonts (Manrope, Unbounded, Michroma): `fonts.googleapis.com`, `fonts.gstatic.com`.
- Больше внешних запросов нет; собственного сервера нет.

## 6. Сборка, тесты, публикация
- Сборки нет. Публикация: ручная загрузка `index.html` и `sw.js` + повышение номера кэша.
- Тесты: Playwright + Chromium, около 55 сценариев (`test*.py`, `audit.py`, `tlib.py`), живут вне репозитория (в рабочей области Claude). Часть устарела. **В репозиторий не добавлены.**

## 7. Швы для разделения (где код уже почти независим)
1. Чистые функции без обращения к DOM: форматирование, даты, `cleanX`, расчёт серий, расчёт лимита и прогнозов.
2. Слой хранения (строки 3473–3759): единственное место, где различаются cloud и local.
3. Автономные модули с узким интерфейсом: дневник, задачи, привычки, челлендж, пин-код, резервная копия, обучение/руководство.
4. Тяжёлые связности (разделять последними): накопления ↔ счета ↔ регулярные платежи ↔ журнал ↔ плитки главного экрана.
