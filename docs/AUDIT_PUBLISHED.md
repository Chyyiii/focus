# FOCUS-001b: повторный аудит опубликованной версии

Объект: клон `Chyyiii/moneyload`, `main`, коммит `50bb8bb`. Код не менялся.

## Результат проверки
- Файлы приложения совпадают побайтно с рабочей версией (см. BASELINE.md).
- Автотесты, запущенные на опубликованном `index.html`: создание и правка записей, переводы, резервная копия и восстановление, привычки, задачи, обучение, демо-режим, дневник/настройка карточки, исключение демо из копии, свёрнутый журнал. Проходят.
- Проверка вёрстки на 8 размерах (320×568 … 1024×768): 0 проблем.
- Единственное сообщение в консоли: `ERR_TUNNEL_CONNECTION_FAILED` (не загружаются шрифты Google в изолированной среде проверки).
- Один сценарий (дневник, test51) падает по ожидаемой причине: он написан до появления правила «карточка дневника после 20:00». Это устаревший тест, не ошибка приложения.

## Поправка к FOCUS-001: инвентаризация была неполной
Повторный проход по коду нашёл функции, которых не было в первом списке. Их тоже нельзя удалять без согласования:
- **Машина времени**: прогноз на год вперёд и сценарий «а что, если».
- **Кредитный калькулятор** и **досрочный платёж**.
- **Подписки**: автоматический поиск повторяющихся трат.
- **Рекомендуемый бюджет** в процентах от дохода.
- **Челлендж** (трекер цели) и **картинка итога для публикации**.
- **Импорт из CSV** и **экспорт в таблицу**.
- **Закрытие месяца** и перенос остатка; «Можно сегодня» и «Не хватает на платежи»; прогноз на конец месяца.
- **Метки**, **расходы по категории** (график), **один платёж на несколько категорий**, быстрая запись одной строкой, напоминания о платежах, «Скрыть суммы», быстрый вход на iPhone.
- 24 всплывающих окна: `ovAdd, ovSave, ovClose, ovHelp, ovDay, ovAcc, ovPie, ovCmp, ovTm, ovLim, ovBud, ovDebt, ovDebtF, ovChal, ovShare, ovTask, ovHab, ovCsv, ovRec, ovExtra, ovRecF, ovSet, ovSvEdit, ovTags`.

Спецификации `openspec/specs/` описывают основные модули. Перечисленные выше возможности в них ещё не покрыты и должны быть добавлены до начала рефакторинга (задача FOCUS-004).

## Изменения репозитория, замеченные при аудите
- Архив `FOCUS-repo-pack.zip` и файл `MASTER_PLAN.md` загружены в корень репозитория как есть. Их нужно распаковать: `MASTER_PLAN.md` в `docs/`, папки `openspec/`, файлы `GIT.md`, `README.md` в корень. Архив из репозитория убрать.
- В git нет пользовательских данных и секретов.

## Риски (без изменений по сравнению с FOCUS-001, плюс новый)
1. Две несвязанные базы данных: артефакт Claude и GitHub Pages.
2. Данные в `localStorage` могут быть очищены браузером; автокопии лежат там же.
3. Обновления GitHub Pages доходят со второго открытия (стратегия кэша).
4. Монолит 7 978 строк в одной области видимости.
5. Устаревшие тесты, нет единого запуска.
6. **Новый, критичный для переезда: `localStorage` привязан к адресу сайта.** При переходе с `chyyiii.github.io` на свой домен данные автоматически не перенесутся; сервис-воркер и установленная иконка «Домой» тоже начнутся заново. Перенос возможен только через файл резервной копии (механизм уже есть и проверен).
