# Дельта спецификации: backup-security

## ADDED Requirements

### Requirement: Статус постоянного хранилища
Приложение SHALL запрашивать постоянное хранилище браузера и показывать в «Настройках» его статус: защищено, не защищено или не поддерживается.

#### Scenario: Браузер не поддерживает API
- **WHEN** `navigator.storage.persist` недоступен
- **THEN** показывается статус «Не поддерживается браузером»
- **AND** остальные функции работают без изменений

### Requirement: Напоминание о копии вне приложения
Приложение SHALL напоминать о сохранении файла копии, если с последнего сохранения прошло более 14 дней и в данных есть записи.

#### Scenario: Напоминание отложено
- **WHEN** пользователь откладывает напоминание
- **THEN** оно не показывается повторно до окончания срока откладывания
