# Дизайн: FOCUS-002

- Запрос `persist()` выполняется один раз при запуске, результат сохраняется в переменной состояния и показывается в «Данные и копии».
- Если API недоступен, статус «Не поддерживается браузером», остальное работает как раньше.
- Напоминание использует существующий ключ `kassa-bk-last` (дата последней копии) и `kassa-bk-snooze` (откладывание).
- Определение режима «установлено на экран Домой»: `matchMedia('(display-mode: standalone)')` и `navigator.standalone`.
- Никаких новых ключей хранения, если без них можно обойтись.
