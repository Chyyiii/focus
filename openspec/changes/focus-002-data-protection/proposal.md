# FOCUS-002 — Защита данных

Статус: READY (ожидает утверждения собственника)

## Цель
Снизить риск потери данных на GitHub Pages и приучить делать копию вне приложения.

## Причина
Аудит FOCUS-001: данные лежат в `localStorage`. Safari может очистить их у сайта, которым давно не пользовались и который не установлен на экран «Домой». Автокопии лежат в том же хранилище, то есть вместе с данными пропадут и они.

## Текущее поведение
- Браузеру не отправляется запрос на постоянное хранилище.
- Напоминаний о копии вне приложения нет, кроме информационных подсказок (`kassa-bk-last`, `kassa-bk-snooze`).

## Требуемое поведение
1. Приложение запрашивает постоянное хранилище (`navigator.storage.persist()`), если оно поддерживается.
2. В «Настройках → Данные и копии» показывается статус: «Хранилище защищено» или «Браузер может очистить данные».
3. Если файл копии не сохранялся более 14 дней, при открытии показывается ненавязчивое напоминание.
4. Если приложение не установлено на экран «Домой», показывается подсказка, как это сделать.

## Ограничения
- Структура хранения данных не меняется.
- Существующие подсказки о копиях не ломаются.
- Нет внешних сервисов и отправки данных.

## Критерии готовности
- Статус хранилища виден и корректен при поддержке и без поддержки API.
- Напоминание появляется по правилу и закрывается с откладыванием.
- Все прежние тесты и проверка вёрстки на 8 размерах экрана проходят.
