# Задачи и привычки

## Requirements

### Requirement: Задачи
Приложение SHALL хранить задачи с текстом, датой, временем, приоритетом (0–2), заметкой и признаком выполнения. Фильтры: «Сегодня», «Скоро», «Без даты», «Готово».

### Requirement: Быстрое добавление
Приложение SHALL позволять добавить задачу одной строкой с выбором срока (сегодня, завтра и др.).

### Requirement: Привычки
Приложение SHALL поддерживать привычки с названием, значком, днями недели и целью по числу дней. Для привычек SHALL считаться серия дней подряд.

#### Scenario: Миграция старого плана
- **WHEN** в данных есть устаревший список `plan`
- **THEN** его записи переносятся в задачи без потери данных
